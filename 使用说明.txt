========================================
  易查分成绩批量查询 —— 使用说明
========================================

【最快用法】

1. 新建一个 txt，一行写一个学生姓名，保存

   例：
       张三
       李四
       王五

2. 把这个 txt 文件拖到「一键查分.bat」上，松手

3. 等它跑完，结果自动放进「成绩输出」文件夹：

       成绩输出\成绩1.xlsx
       成绩输出\成绩2.xlsx   ← 再跑一次就是这个，不会覆盖上一次

就这么简单。第一次运行会自动装 openpyxl（需要联网）。


【★ 跑之前先确认：查的是哪一次】

每次运行都会先在屏幕上打一段：

    ================================================
      本次查询：某某班第三次练习成绩
      查询码  ：xxxxxxxxx
      发布时间：2026-12-01 10:00:00
      凭据来源：微信缓存，最后打开于 2026-12-01 10:20
      待查人数：72 人 × 12 秒
    ================================================

看到「本次查询」不是你想要的那一份，就直接关窗口，别让它跑。


【★ 成绩一个月出一次，怎么自动跟上最新的】

程序**每次都会重新扫微信缓存**，取你最后打开过的那次查询：

  1. 老师在群里发了新链接 → 先在【微信电脑端】点开一次那个查询
     （随便查一个人看到结果就行，不用停留）
  2. 回来双击「一键查分.bat」
  3. 它会自动选中最新那次，横幅上会显示新的查询名称

不需要删配置、不需要改任何文件。

如果同时存在好几份查询，它会列出其他的，并带上中文名字：

    [i] 还能查这些（按最近打开排序）：
        1) 某某班第一次练习    aaaa1111   发布 2026.10.01  最近打开 11-08 20:40
        2) 英语周测         bbbb2222   发布 2026.10.23  最近打开 11-08 19:40

        想换某一份，把 --uq-code 后面换成它的查询码，例如：
          python cli.py --names 班级名单.txt --uq-code bbbb2222


【★ 想换一份查？双击「选择查询.bat」】

不用记那些查询码。双击「选择查询.bat」，它会：

  1. 列出你账号下所有的查询（服务端给的中文名，不会认错）
  2. 标出「← 当前在用」的那一份
  3. 你输入编号回车，它就把设置改好

    ============================================================
      已知的查询
    ============================================================
      1) 某某班第一次练习    aaaa1111   发布 2026.10.01  最近打开 11-08 20:40
      2) 英语周测         bbbb2222   发布 2026.10.23  最近打开 11-08 19:40
      3) 某某班第二次练习成绩  cccc3333   发布 2026.11.07  最近打开 —   ← 当前在用
    ============================================================

      要查第几个？直接回车 = 保持现在的 cccc3333:

选完下次双击「一键查分.bat」就查那一份。


【命令行方式换一份】

格式（--uq-code 后面直接跟那串码，不要加引号）：

    python cli.py --names 班级名单.txt --uq-code bbbb2222

完整例子 —— 查「英语周测」，名单用班级名单.txt，间隔 20 秒：

    python cli.py --names 班级名单.txt --uq-code bbbb2222 --delay 20

其中：
    --names    名单文件（一行一个姓名）
    --uq-code  要查哪一份，从「选择查询.bat」里抄
    --delay    每人间隔秒数，可不写（默认 12）


【★ 必须是「微信电脑端」】

本工具靠读微信电脑版（Windows/Mac 版微信）的本地缓存来拿身份，
手机微信、网页版微信都抓不到。

而且：微信重启或定期清理会删掉这段缓存。所以第一次用、或者隔了很久没用，
都要先在微信电脑端打开一次那个查询，再运行脚本。

如果是同一台电脑同一个微信、前几天刚跑过，通常直接跑就行。


【调整查询间隔（防限流）】

易查分有反爬限制，查太密会被临时封禁。

双击「设置间隔.bat」，按提示输入秒数：

     6  秒   快，但接近触发点，不推荐
    12  秒   默认，一个班 70 人约 14 分钟
    20  秒   稳，约 23 分钟
    30  秒   最保险，约 35 分钟

也支持临时指定：

    python cli.py --names 姓名.txt --delay 25


【如果报错】

● 找不到 Python
  去 https://www.python.org/downloads/ 装，安装时务必勾选最下面的
  "Add Python to PATH"，装完重新双击 bat。

● 找不到 openidCode
  先在微信电脑端打开一次那个查询小程序（随便查一个人），再运行。

● 提示「触发限流，等待 N 分钟后继续」
  程序会自动等待重试，别关窗口。已查到的存在 ycf-cache.json 里，
  中断重跑会跳过已完成的。

● 换了另一份成绩，但结果像是上一次的
  不会了。缓存现在按「查询码」分开存，不同查询之间不会串数据。
  如果你看到旧的 ycf-cache.json（升级前生成的），程序会自动丢弃它重抓。

● 提示「姓名不正确」
  那个名字不在名单里，或者字打错了。易查分是精确匹配，不支持模糊。


【本目录文件说明】

   一键查分.bat        ← 入口，双击或拖拽姓名文件
   设置间隔.bat        ← 改查询间隔
   interval.txt        ← 间隔秒数
   姓名示例.txt        ← 姓名文件模板
   ycf-config.json     ← 记住上次用的查询码（自动生成，别外传）
   ycf-cache.json      ← 断点续抓缓存（自动生成）
   成绩输出\           ← 每次结果都放这里，自动编号

   README.md           ← 完整文档，含接口原理


【命令行方式（高级）】

在本目录 Shift + 右键 → 在此处打开 PowerShell：

    python cli.py --names 姓名.txt --delay 20 --out 结果.xlsx

常用参数：

    --uq-code XXX     指定查哪一份（不给就自动取最新的）
    --openid XXX      手动指定微信身份
    --delay 20        每人间隔秒
    --yes             跳过确认，直接开跑

查看全部：python cli.py --help


【原理一句话】

易查分的查询在微信小程序里，网页端被老师关了。本工具把小程序那三个
接口还原出来，用你微信的身份批量查，再整理成 Excel。
详细说明见 README.md。
